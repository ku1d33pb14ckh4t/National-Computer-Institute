Chapter 1: Introduction to Web Design — Complete Syllabus

1.1 Introduction to World Wide Web (WWW)

World Wide Web (WWW) एक Information System है जहाँ Documents और Resources Internet पर Hyperlinks के माध्यम से जुड़े होते हैं। इसे Tim Berners-Lee ने 1989 में Invent किया था। Web Pages HTML में लिखे जाते हैं और Web Browsers के माध्यम से Access किए जाते हैं।

1.2 Web Page vs Website vs Web Server

TermDefinitionExample
Web PageSingle HTML Document जो Browser में Display होता हैindex.html, about.html
WebsiteRelated Web Pages का Collection जो Single Domain के Under होते हैंwww.nielit.gov.in
Web ServerComputer जो Websites को Host करता है और User Requests को Respond करता हैApache, Nginx, IIS
Web BrowserSoftware जो Web Pages को Render और Display करता हैChrome, Firefox, Edge
Web PortalGateway जो Multiple Services और Links Provide करता हैYahoo, MSN, Rediff

1.3 Types of Websites

  • Static Website: Fixed Content वाली Website जो Server से Directly Serve होती है। HTML, CSS से बनती है। Fast Loading लेकिन Less Interactive। Examples: Portfolio, Brochure Sites
  • Dynamic Website: Database-driven Content वाली Website जो User Input के अनुसार Change होती है। PHP, ASP.NET, Node.js से बनती है। Interactive और Personalized। Examples: Facebook, Amazon, Flipkart

  • E-Commerce Website: Online Buying और Selling की सुविधा देने वाली Website | Payment Gateway, Shopping Cart, User Accounts होते हैं | Examples: Amazon, Flipkart, Myntra
  • Blog Website: Regularly Updated Content वाली Website जहां Articles, Posts Publish होते हैं। WordPress, Blogger पर बनती है। Examples: TechCrunch, Mashable

1.4 Web Design Principles

Effective Web Design के लिए निम्नलिखित Principles को Follow करना आवश्यक है:

  • Balance: Page Elements को Symmetrical या Asymmetrical तरीके से Arrange करना ताकि Visual Harmony बनी रहे
  • Contrast: Colors, Sizes, Fonts में Difference Create करना ताकि Important Elements Highlight हों
  • Emphasis: Key Content को Attention Draw करने के लिए Bold, Color, Size का उपयोग
  • Consistency: पूरी Website में Same Design Pattern Follow करना — Colors, Fonts, Layout, Navigation
  • Unity: सभी Elements को Organized और Connected रूप में रखना ताकि Cohesive Experience मिले
  • Proximity: Related Elements को पास में रखना और Unrelated Elements को अलग
  • Alignment: Elements को Left, Right, Center, या Justify करके Clean Look देना
  • White Space: Empty Space का Smart Use करना ताकि Content Readable रहे
  • Navigation: Easy और Intuitive Menu System ताकि User कहीं भी जा सके
  • Accessibility: Disabled Users के लिए भी Website Usable हों

Chapter 2: HTML Basics — Complete Syllabus

2.1 Introduction to HTML

HTML (HyperText Markup Language) Web Pages बनाने की Standard Markup Language है। HTML Tim Berners-Lee द्वारा 1991 में Develop की गई। HTML Tags का उपयोग करके Content को Structure और Format करती है। HTML5 Latest Version है जो Multimedia Support, Semantic Elements, और APIs Provide करता है।

HTML की मुख्य विशेषताएं:

  • Platform Independent: किसी भी OS पर Run होती है
  • Easy to Learn: Simple Tags और Syntax
  • Case Insensitive: <html>, <HTML>, <Html> सभी Valid है
  • Free and Open: No License Required
  • Browser Compatible: सभी Modern Browsers Support करते हैं
  • Extensible: CSS और JavaScript के साथ Extend की जा सकती है

2.2 HTML Document Structure

Basic HTML Document की Structure निम्नलिखित है:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Page Title</title> </head> <body> <h1>This is a Heading</h1> <p>This is a paragraph.</p> </body> </html>

Structure Explanation:

  • <!DOCTYPE html>: Document Type Declaration जो Browser को बताता है कि यह HTML5 Document है
  • <html>: Root Element जो पूरे HTML Document को Wrap करता है
  • <head>: Meta Information जैसे Title, Charset, Styles, Scripts रखता है। Browser में Display नहीं होता
  • <body>: Visible Content जो User को Browser में दिखता है

Chapter 4: CSS (Cascading Style Sheets) — Complete Syllabus

4.1 Introduction to CSS

CSS (Cascading Style Sheets) Web Pages को Style और Design देने की Language है। CSS Håkon Wium Lie द्वारा 1994 में Propose की गई। CSS HTML Elements की Color, Font, Size, Position, Layout, Animation Control करती है। CSS3 Latest Version है जो Animations, Transitions, Flexbox, Grid, Media Queries जैसे Advanced Features Provide करता है।

CSS की मुख्य विशेषताएं:

  • Separation of Concerns: Content (HTML) और Presentation (CSS) अलग-अलग
  • Reusability: एक CSS File Multiple HTML Pages में Link की जा सकती है
  • Consistency: पूरी Website में Uniform Design
  • Easy Maintenance: एक जगह Change करने से पूरा Site Update होता है
  • Faster Loading: Browser CSS File Cache करता है
  • Responsive Design: Mobile, Tablet, Desktop सभी Devices पर अच्छा दिखना
