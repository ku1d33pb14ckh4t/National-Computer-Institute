🔷 PART 1: HTML की हर Line

Line 2: <html>

<html>

Line 3: <head>

<head>

🎨 PART 2: CSS की हर Line

Reset Section

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
  font-family: 'Segoe UI', Arial, sans-serif;
}
PropertyValueमतलब
*—Universal selector — सभी elements को select करता है
margin0बाहर की खाली जगह हटा दी
padding0अंदर की खाली जगह हटा दी
box-sizingborder-boxpadding + border को width/height में शामिल करता है
font-family'Segoe UI', Arial, sans-serifपहले Segoe UI, न मिले तो Arial, न मिले तो कोई भी sans-serif

box-sizing: border-box example: बिना border-box: width:200px + padding:20px = 240px total | border-box के साथ: width:200px + padding:20px = 200px total

📄 PART 3: HTML Body की हर Line

Form Container

<div class="form-box">
  • div → Block container. class="form-box" → CSS से जोड़ता है।

Form Tag

<form action="#" method="post">
AttributeValueमतलब
action#Data कहाँ भेजना है (# = वही page)
methodpostData भेजने का तरीका (URL में नहीं, body में)

Text Input

<input type="text" id="name" name="name" placeholder="अपना नाम लिखें" required>
Attributeमतलब
type="text"Normal text input
id="name"Unique ID (CSS/JS के लिए)
name="name"Backend पर भेजे जाने वाला नाम
placeholderअंदर दिखने वाला hint
requiredभरना ज़रूरी है

Email Input

<input type="email" ... required>

type="email" → Browser ख़ुद check करता है कि @ और . हैं।

Password Input

<input type="password" ... minlength="6" required>
  • type="password" → Dots में दिखता है।
  • minlength="6" → कम से कम 6 characters।

Phone Input

<input type="tel" ... pattern="[0-9]{10}">
  • type="tel" → Mobile पर numeric keypad।
  • pattern="[0-9]{10}" → सिर्फ 10 digits allowed।

Pattern breakdown: [0-9] = कोई भी digit 0 से 9, {10} = ठीक 10 बार

Date Input

<input type="date" id="dob" name="dob">

type="date" → Calendar picker।

Radio Buttons

<input type="radio" name="gender" value="male" checked>
Attributeमतलब
type="radio"एक ही चुन सकते हैं
name="gender"Same name वाले radios में से एक ही select होगा
value="male"Submit होने पर भेजी जाने वाली value
checkedDefault selected

Select Dropdown

<select id="city" name="city">
  <option value="">-- चुनें --</option>
  <option value="delhi">दिल्ली</option>
</select>
  • <select> → Dropdown।
  • <option> → हर choice।
  • value="" → खाली value (default placeholder)।

File Upload

<input type="file" id="photo" name="photo" accept="image/*">
  • type="file" → File chooser।
  • accept="image/*" → सिर्फ images (image/png, image/jpeg आदि)।

Submit & Reset Buttons

<button type="submit" class="btn btn-submit">Submit</button>
<button type="reset" class="btn btn-reset">Reset</button>
Attributeमतलब
type="submit"Form भेजता है
type="reset"सारे fields खाली करता है
class="btn btn-submit"दो classes (space से अलग)

Practice Task

border-radius: 15px → 50px — क्या बदलता है?
#667eea → #ff6b6b — gradient लाल हो जाएगा।
transition: 0.3s → 1s — animation धीमी हो जाएगी।
box-shadow blur 40px → 100px — shadow फैलेगी।
gap: 15px → 50px — items दूर होंगे।

हर change के बाद browser refresh करके देखें! 🔍
